# 🎬 Netflix-clone Landing Page Clone

A responsive, pixel-perfect front-end clone of the **Netflix India** landing page. Built purely with semantic HTML5, modern CSS3 layout techniques, and lightweight vanilla JavaScript for interactive components.

---

## 🚀 Live Demo

Check out the live website here:  
👉 **[Live Preview Link](https://<https://tarunkaushik00.github.io/netflix-ui-clone/>.github.io/<netflix-ui-clone>/)**  

---

## ✨ Features

- **Hero Section:** High-resolution backdrop overlay, official branding, and call-to-action email input.
- **Top 10 Trending Slider:** Interactive movie carousel featuring rank indicators and smooth horizontal scrolling.
- **Feature Showcase:** Clean grid cards highlighting platform features (Enjoy on TV, Download offline, Kids profile).
- **Accordion FAQs:** Interactive questions and answers built using native HTML `<details>` and `<summary>` tags with animated toggles.
- **Fully Responsive Design:** Optimized for mobile screens, tablets, and desktop displays via targeted CSS media queries.
- **Custom UI Styling:** Neon gradient accents, hover lift animations, and customized WebKit scrollbars.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic markup structure.
- **CSS3:** Flexbox, CSS Grid, custom scrollbars, and media queries.
- **JavaScript (ES6):** Smooth slider button scrolling.
- **FontAwesome:** Icons for navigation and UI elements.
